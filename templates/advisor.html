Scientific Methodology & Model Validation
Empirical Validation of the 99.3% Model Accuracy
Supervised multiclass machine learning evaluation across 22 benchmark crop profiles.
Dataset & Features
2,200 Agricultural Observations
22 crop classes (100 samples/class). 7 input dimensions: Soil N, P, K, pH, Temperature, Humidity, and Rainfall.
Partitioning & Cross-Validation
Stratified 80/20 Train/Test Split
1,760 training samples and 440 unseen testing samples. Evaluated using 5-fold cross-validation with random seed 42.
Model Comparison & Test Results:
Algorithm Hyperparameters Test Accuracy Status
Random Forest Classifier 100 Estimators, Gini Index 99.32% (~99.3%) Active Production Model
Decision Tree (CART) Max Depth: None, Gini 98.41% Baseline
Gaussian Naive Bayes Priors: Empirical 99.09% Baseline
Distinction Between Overall Accuracy and Per-Prediction Confidence:
• 99.3% Validation Accuracy: Measures the global performance of the Random Forest model on the 440 held-out test records.
• Per-Prediction Confidence Score: Represents the posterior probability distribution output by predict_proba() for that specific soil and weather vector. Unlike the static 99.3% test metric, per-prediction scores reflect sample-specific certainty (e.g. 84%, 96%) when climate parameters overlap multiple crop ranges.
